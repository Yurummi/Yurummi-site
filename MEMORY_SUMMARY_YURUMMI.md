## 1. Персонаж и Маскот Стримера (Юрумми / Yurummi)

При создании артов, баннеров, виджетов и оформлении сайта строго соблюдаются следующие черты персонажа:

* **Раса / Вид**: Некомими (девочка-кошка / catgirl).
* **Ушки и хвост**: Большие пушистые белые кошачьи ушки с нежной пастельно-розовой шерсткой внутри; длинный, мягкий, пушистый белый кошачий хвост.
* **Цвет и причёска волос**:
  * Базовый цвет: тёплый каштановый / молочно-шоколадный с мягким розоватым отливом (не серый, не пепельный, не зелёный).

  * Причёска: два длинных низких хвостика (low twin-tails), перекинутых вперёд на грудь/плечи.
  * **КРИТИЧЕСКИЙ ГРАДИЕНТ КОНЧИКОВ**:
    * **Левый хвостик (от зрителя)**: плавный переход в глубокий насыщенный фиолетовый цвет (purple/violet), фиолетовая резинка/скранч.
    * **Правый хвостик (от зрителя)**: плавный переход в яркий неоновый леденцово-розовый цвет (hot pink / candy magenta), розовая резинка/скранч.
* **Лицо и глаза**: Выразительные круглые аниме-глаза (doe-eyes) с градиентной радужкой цвета маджента-фиолетовый, мягкий румянец на щёчках. На шее — классический тонкий чёрный чокер.
* **Ключевые образы персонажа в проекте**:
  1. *Cozy White Sweater*: оверсайз белый трикотажный свитер со спущенными плечами, открывающими ключицы, короткая тёмная юбка, белые чулки выше колена.

## 3. Выполненные Задачи и Правила Кодовой Базы

### 3.1. Медиа-библиотека и Франшизы (`stats.html`, `js/stats.js`, `js/media-data.js`)
* **Сохранение вкладки при перезагрузке**:
  * Реализовано через `sessionStorage.getItem('yurummi_stats_active_tab')`.
  * При перезагрузке со вкладки «Игры» пользователь остаётся на ней, его больше не сбрасывает на «Аниме».
* **Индикатор серий на карточках**:
  * Одиночный тайтл: бейдж в правом верхнем углу `📺 {eps} сер.`.
  * Тайтл из франшизы: `📺 {eps} сер. / {total} сер.` с фиолетовой подсветкой и подсказкой обо всех сезонах.
* **Полка франшиз в модальном окне**:
  * Автоматически собирает все связанные сезоны через `franchise: "<key>"`.
  * Отображает общее число сезонов с правильным склонением: *«2 сезона»*, *«4 сезона»*, *«5 сезонов»*, *«8 сезонов»*.
  * Карточки сезонов внутри модалки кликабельны и позволяют бесшовно переходить между сезонами тайтла.
  * Устранён баг с `translateY(-2px)`, из-за которого карточка при наведении выскакивала за верхний край скролл-контейнера и обрезалась. Добавлен `padding: 4px 6px 6px 4px`.
  * Устранено обрезание слова «Текущий» до «ТЕКУЩИ» — бейдж `⭐ Текущий` вынесен в строку метаданных карточки.
* **Каноническая сортировка сезонов (`getSeasonOrderNum`)**:
  * Функция распознает арки и подзаголовки (*девочки-зайки*, *Санта-Клаус*, *кусочек*, *Квартал красных фонарей*, *Деревня кузнецов*, *Тренировка Хашира*, *Восстань из тени* и т.д.), выстраивая карточки строго по сюжетному порядку (1 ➔ 2 ➔ 3 ➔ 4).

## 4. Гайдлайн для любого следующего ИИ-ассистента на ПК

1. **Не ломать offline-first архитектуру**: Все данные читаются синхронно из `window.MEDIA_DATA`, `window.STEAM_GAMES` и `window.CUSTOM_GAMES`. Никаких внешних `fetch()` в рантайме клиента — всё статично и работает без интернета.
2. **Формат базы `js/media-data.js`**:
   * Обертка строго: `window.MEDIA_DATA = { "stats": { "total": ..., "anime": ..., "manga": ..., "movies": ..., "watched": ..., "watching": ..., "planned": ... }, "items": [ ... ] };`
   * Все новые тайтлы должны иметь валидные поля: `title`, `rating`, `tier`, `review`, `desc`, `poster`, `url`, `status`, `category`, `episodes`, `kind`, `franchise`.
3. **Сохранение стиля и комментариев**: Сохранять все существующие русскоязычные комментарии и архитектуру селекторов в CSS и JS.
